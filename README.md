# Last Text at One Percent

The funniest final text message a dying phone sends at one percent battery — written in the phone's own voice, under 200 characters. It spent its last percent on this text instead of calling for help, died with 47 tabs open, and regrets none of them.

## Run

```sh
node main.ts
```

This writes the phone's final text to `./output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Requires Node 22 or later.
